# LLM Fine-Tuning Workspace

Notebook workspace for language-model engineering practice, with Hugging Face fine-tuning exercises and experiment artifacts.

## What It Does

- Stores LLM fine-tuning notebooks and supporting material.
- Captures hands-on practice with Hugging Face model workflows.
- Provides a reference point for learning tokenization, training loops, and model experimentation.

## Tech

Python, Jupyter Notebook, Hugging Face, LLM fine-tuning.
